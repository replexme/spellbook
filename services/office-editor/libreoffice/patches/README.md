# Ordered patch series

The order and aggregate byte hash of these patches are locked by `../upstream.json`. Later patches may extend tests or implementation introduced earlier, so apply the complete series cumulatively.

Each engine change must have a native regression test for the violated invariant: one Undo boundary, exact Undo/Redo, failure rollback, object identity, master/layout preservation, or save/reopen semantics. Case-specific slide numbers, object names, coordinates and corpus identifiers are not valid production conditions.

The current `undo-v31` source candidate extends the cumulative series through table API inheritance, table text-cursor Undo, exact existing-master layout selection, observable mixed-script text formatting, native object creation/duplication, metric-driven text-layout invalidation, sparse-master-safe slide insertion, bounded object interactions, slide metadata, line style, paragraph formatting, slide sections, the complete animation-effect lifecycle, document design, advanced shape/text/connector mutation and semantic assets/accessibility in `0027`–`0043`. Patch `0036` moves PPTX click-action serialization to one shared shape-export boundary. Patch `0037` replaces the picture-placeholder-only URL workaround with the general OOXML inheritance rule: master and layout values are inherited first, then already parsed local non-visual properties win. Patch `0038` adds typed page, line and paragraph mutations with one native Undo boundary and PPTX reopen coverage. Patch `0039` gives section definitions one atomic Undo and PPTX round-trip boundary. Patch `0040` exposes preset-backed animation add, remove, replace and reorder without flattening the animation tree. Patch `0041` adds document-wide slide sizing plus master theme colors and major/minor font schemes, and fixes complete theme copying so format schemes are never dropped. Patch `0042` adds bounded gradients, hatches, effects, language/case/list handling, connectors and freeform geometry. Patch `0043` adds identity-preserving image/media replacement, media playback, semantic SmartArt nodes, Math source, Fontwork, 3D material and reading order, with separate media content/history regression coverage. Patch `0044` applies media and reading-order changes through their native models, makes last-line alignment semantically valid, synchronizes delayed animation rebuilds before Undo, and treats the format's one-unit size quantization as outline-equivalent. Patch `0045` corrects the native navigation index, keeps authored media properties authoritative over live player feedback, and removes an unsupported independent last-line property. Patch `0046` enables the actual line-style mode in typed object edits and covers Undo/Redo and PPTX reopen. Patch `0047` restores full authored media snapshots despite MediaItem update masks and records paragraph UNO values for native Undo/Redo. Patch `0048` checks PPTX-reopened marker geometry rather than LibreOffice palette labels. Patch `0049` restores fixed slide-date metadata when importing a PPTX date placeholder. Patch `0050` checks the actual `PolyPolygonBezierCoords` type returned by reopened line markers instead of interpreting it as `PointSequence`. Patch `0051` preserves auto-advance timing in milliseconds through PPTX save/reopen even for slides without a visual transition and keeps the mode in the metadata Undo snapshot. Patch `0053` keeps the visual transition of a slide that also advances automatically, which `0051` had dropped on reload. Patch `0054` stores typed character spacing in the model's 1/100 mm unit instead of twips. Patch `0055` makes attribute Undo and Redo on a text object restore the saved object items exactly, so an attribute applied to the selected object no longer survives its Undo at object level. Patch `0056` writes a SmartArt frame with the shape's own name and alternative text instead of "Diagram" plus the diagram number. Patch `0057` gives a PPTX paragraph without `marR` no right margin; inserting a paragraph copied the previous paragraph's attributes, so its right margin carried over on import. Patch `0058` makes replacing an animation effect scale the new preset's animations to the kept duration; the effect had kept its stored duration while playing at the preset's own timing. Patch `0059` makes the metadata, line and paragraph test edit its title placeholder the way every editing path does: setting the model text directly left the placeholder marked empty, so PPTX export wrote it without its paragraphs and the reopened paragraph had no margins. `sourcePatchSeriesReady` records only clean application to the pinned source. `sourceCandidateReady` remains false until the single final integrated build and both declared C++ suites pass. Runtime promotion remains separate and requires the browser, OOXML, visual and PowerPoint checks described in the parent README.
