# Ordered patch series

The order and aggregate byte hash of these patches are locked by `../upstream.json`. Later patches may extend tests or implementation introduced earlier, so apply the complete series cumulatively.

Each engine change must have a native regression test for the violated invariant: one Undo boundary, exact Undo/Redo, failure rollback, object identity, master/layout preservation, or save/reopen semantics. Case-specific slide numbers, object names, coordinates and corpus identifiers are not valid production conditions.

The current `undo-v31` source candidate extends the cumulative series through table API inheritance, table text-cursor Undo, exact existing-master layout selection, observable mixed-script text formatting, native object creation/duplication, metric-driven text-layout invalidation, sparse-master-safe slide insertion, bounded object interactions, slide metadata, line style, paragraph formatting, slide sections, the complete animation-effect lifecycle, document design, advanced shape/text/connector mutation and semantic assets/accessibility in `0027`–`0043`. Patch `0036` moves PPTX click-action serialization to one shared shape-export boundary. Patch `0037` replaces the picture-placeholder-only URL workaround with the general OOXML inheritance rule: master and layout values are inherited first, then already parsed local non-visual properties win. Patch `0038` adds typed page, line and paragraph mutations with one native Undo boundary and PPTX reopen coverage. Patch `0039` gives section definitions one atomic Undo and PPTX round-trip boundary. Patch `0040` exposes preset-backed animation add, remove, replace and reorder without flattening the animation tree. Patch `0041` adds document-wide slide sizing plus master theme colors and major/minor font schemes, and fixes complete theme copying so format schemes are never dropped. Patch `0042` adds bounded gradients, hatches, effects, language/case/list handling, connectors and freeform geometry. Patch `0043` adds identity-preserving image/media replacement, media playback, semantic SmartArt nodes, Math source, Fontwork, 3D material and reading order, with separate media content/history regression coverage. Patch `0044` applies media and reading-order changes through their native models, makes last-line alignment semantically valid, synchronizes delayed animation rebuilds before Undo, and treats the format's one-unit size quantization as outline-equivalent. Patch `0045` corrects the native navigation index, keeps authored media properties authoritative over live player feedback, and removes an unsupported independent last-line property. Patch `0046` enables the actual line-style mode in typed object edits and covers Undo/Redo and PPTX reopen. Patch `0047` restores full authored media snapshots despite MediaItem update masks and records paragraph UNO values for native Undo/Redo. Patch `0048` checks PPTX-reopened marker geometry rather than LibreOffice palette labels. Patch `0049` restores fixed slide-date metadata when importing a PPTX date placeholder. Patch `0050` checks the actual `PolyPolygonBezierCoords` type returned by reopened line markers instead of interpreting it as `PointSequence`. Patch `0051` preserves auto-advance timing in milliseconds through PPTX save/reopen even for slides without a visual transition and keeps the mode in the metadata Undo snapshot. Patch `0053` keeps the visual transition of a slide that also advances automatically, which `0051` had dropped on reload. Patch `0054` stores typed character spacing in the model's 1/100 mm unit instead of twips. Patch `0055` makes attribute Undo and Redo on a text object restore the saved object items exactly, so an attribute applied to the selected object no longer survives its Undo at object level. Patch `0056` writes a SmartArt frame with the shape's own name and alternative text instead of "Diagram" plus the diagram number. Patch `0057` gives a PPTX paragraph without `marR` no right margin; inserting a paragraph copied the previous paragraph's attributes, so its right margin carried over on import. Patch `0058` makes replacing an animation effect scale the new preset's animations to the kept duration; the effect had kept its stored duration while playing at the preset's own timing. Patch `0059` makes the metadata, line and paragraph test edit its title placeholder the way every editing path does: setting the model text directly left the placeholder marked empty, so PPTX export wrote it without its paragraphs and the reopened paragraph had no margins. Patch `0060` writes the paragraph properties of a left-aligned paragraph with default line spacing whenever it has its own margins, indents, spacing, direction or tab stops; such a paragraph was saved without them, so a right margin alone was lost. Patch `0061` keeps the alignment of a shape without text: import holds an empty paragraph's alignment on the shape, and export now writes it from there instead of from the empty paragraph, which does not carry the shape's own attributes. Patch `0062` saves a connector with the exact size between its end points; the box was built from the closed rectangle between them, so every save grew the connector by one unit each way. Patch `0063` adds the write-only shape properties `SpellbookFreeformPolygon` and `SpellbookFreeformPolyline`, which give a custom shape the freeform geometry PPTX import creates for `a:custGeom`; a freeform built as a LibreOffice polygon reopened from PPTX as a different object. Patch `0064` keeps a comment where it was: import converted a legacy comment's position through whole 1/100 mm into 15.87 mm steps, and when the threaded comment part the editor also writes is read instead, it has no position at all, so each comment takes its position from the older part by author and text. Patch `0065` gives a PPTX paragraph without `rtl` a left-to-right direction and one without a tab list no tab stops, and keeps the tab stops of a paragraph with an indent: inserting a paragraph copied the previous paragraph's attributes, so a right-to-left direction and tab stops carried over on import, and the indent rule replaced a paragraph's own tab stops with one at zero. Patch `0066` adds the shape properties `SpellbookLineDash`, `SpellbookLineStartArrow` and `SpellbookLineEndArrow`: setting one applies a PowerPoint dash or arrowhead through the same code PPTX import uses for `a:prstDash`, `a:headEnd` and `a:tailEnd`, as one attribute Undo step, and reading one reports what PPTX export writes, through the export's own dash and arrowhead detection; line styles were only addressable by the document's own style names, which a deck without dashed lines does not have and which import renames. Patch `0067` keeps a run's language on the text it belongs to: PPTX stores one language per run and the export writes it from the locale of the script the run's text is written in, but the import read it into the locale of the language's own script, so a Korean language on Latin text came back as the document default and the next save wrote that default over the language PowerPoint shows. `sourcePatchSeriesReady` records only clean application to the pinned source. `sourceCandidateReady` remains false until the single final integrated build and both declared C++ suites pass. Runtime promotion remains separate and requires the browser, OOXML, visual and PowerPoint checks described in the parent README.
