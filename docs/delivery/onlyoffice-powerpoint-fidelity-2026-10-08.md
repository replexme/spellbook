# ONLYOFFICE와 PowerPoint 화면 일치 개선

사용자 지시: 최근 교체한 ONLYOFFICE를 유지하고, PowerPoint를 항상 숨긴 백그라운드 상태에서 열어 캡처하며 기존 전체 사례의 차이를 조사하고 원인을 수정한다. 제품 코드와 회귀 검증은 공개 코어에서 작업한다. 고객 문서·캡처·개별 파일 식별자는 Git 밖의 평가 자료에 둔다.

## 완료 기준과 진행

- [x] 현재 엔진 선택과 문서 처리기의 미리보기 연결 확인. 편집은 ONLYOFFICE, 미리보기는 여전히 LibreOffice로 등록돼 있다.
- [x] 기존 PowerPoint 백그라운드 실행 도구 확인. 숨김·비활성 상태 확인, 소유 프로세스만 정리하는 절차를 유지한다.
- [x] 전체 입력 목록 확정: 실전 30개, 공개 64개, 실제 오류 문서 원본/저장본, 정본 편집 명령 94개의 원본·저장 결과. 실패·미지원·입력 누락을 제외하지 않는다.
- [ ] 동일 입력의 PowerPoint PNG/PDF와 현재 ONLYOFFICE 화면을 새 실행에서 확보한다.
- [ ] 열기·변경 없는 저장·편집 저장·재열기의 차이를 분리하고 글꼴, 텍스트 배치, 표, 이미지, 마스터/레이아웃, 차트/SmartArt, 효과, 숨김/애니메이션 등 원인별 목록을 작성한다.
- [ ] 편집과 서버 미리보기에 같은 고정 ONLYOFFICE 렌더 경로를 적용한다. 파일 안전 검사와 변경 범위 검증을 유지한다.
- [ ] 확인된 화면 차이의 원인을 수정하고 같은 파일로 전후 및 전체 회귀를 검증한다.
- [ ] 중복 제품 화면과 필수 저작권 표시를 검토한다. 적용 배포판의 로고·법적 고지를 임의로 제거하지 않는다.
- [ ] 변경 파일과 원래 지시를 다시 검토하고 구현·실측·남은 차이를 각각 보고한다.

픽셀 차이 수치만으로 고객 품질을 통과 처리하지 않는다. 실제 캡처와 문서 구조를 함께 확인한다. 기존 LibreOffice 차이 분석은 조사할 기능 범위를 찾는 자료이며 현재 ONLYOFFICE의 결함 증거로 사용하지 않는다. PowerPoint의 macOS/Windows 차이와 고정 글꼴 환경도 별도 기록한다.


## 2026-10-08 검증 체크포인트

현재 작업은 부분 완료다. 운영 배포는 변경하지 않았다.

- 전체 입력 203개를 확정했다. 실제 문서 30개, 공개 사례 64개, 고객 원본/저장본 2개, 정본 명령에서 사용하는 서로 다른 입력 13개, 이전 명령 실행의 저장본 94개다. 이전 저장본은 이번 코드의 명령 실행 증거가 아니다.
- 새 글꼴 환경에서 ONLYOFFICE는 202개 전체 슬라이드를 캡처했다. 외부 연결 이미지만 있는 1개는 변환 단계에서 멈췄으며 원인은 조사 중이다. 실패를 제외하지 않는다.
- PowerPoint는 숨김·비활성 상태에서 188개 문서 842개 슬라이드를 확보했다. 표 원본과 그 저장본 등을 포함한 15개는 열기 시간 제한에 걸렸다. 원본도 실패하므로 편집 결함으로 단정하지 않는다. 원인이 확인되기 전에는 호환성 통과로 처리하지 않는다.
- 실제 설치 글꼴과 별칭·스타일을 수집해 로컬 진단 묶음에 포함했다. 공식 출처로 71개 글꼴 파일을 추가 설치했다. 지정된 나눔스퀘어 네오 Light, Gill Sans MT, Droid Serif, HeadLineA의 실제 선택을 기록했다. 이 묶음은 공개 배포 글꼴로 승인하지 않았으며 독점 글꼴을 저장소에 넣지 않았다.
- DrawingML의 분산 정렬을 일반 양쪽 정렬로 읽고 저장하던 SDK 변환과 배치 오류를 수정했다. 숫자·한글·영문·히브리어·아랍어 및 마지막 줄·단일 단어를 포함한 12개 슬라이드를 PowerPoint와 비교하고 화면을 확인했다. 픽셀 유사도를 호환성 비율로 해석하지 않는다.
- 편집과 서버 미리보기에서 동일한 네이티브 슬라이드 그리기를 공유하도록 구현했다. 공개 코어 및 실제 비공개 처리기의 DI와 로컬 이미지/릴리스 계약을 변경했다. 컨테이너의 실제 .NET 도구로 미리보기 PNG 생성과 화면을 확인했다. 운영 배포 및 비공개 어댑터 이미지 검증은 별도 미완료다.
- .NET 149개, 네이티브 캡처/SDK 관련 Node 25개, 비공개 배포 계약 14개 검사가 통과했다. Replex 계약 검사는 실패 0개다. 이 검사들은 전체 편집 명령과 화면 호환성 검증을 대신하지 않는다.

- [ ] SmartArt 누락의 레이아웃 알고리즘, 3D 차트와 남은 텍스트 배치를 원본 구조·네이티브 모델·실제 화면으로 조사하고 회귀를 검증한다. 강제로 미지원 SmartArt를 생성했으나 위치가 틀린 실험은 폐기했다.
- [ ] 현재 커밋으로 정본 94개 명령 전체를 실제 편집·저장·재열기·실행 취소·복구 과정까지 새로 검증한다. 형식상 제외된 명령 4개는 별도로 유지한다.
- [ ] 실제 비공개 처리기 이미지를 같은 공개 소스/배포판으로 빌드하고 실행·렌더러 정보를 확인한다.

- [ ] 공급자 화면/필수 로고 조건, 전체 회귀와 남은 위험을 검토한 후 배포 결과를 따로 확인한다.
